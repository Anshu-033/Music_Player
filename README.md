# 🎵 Music Player

A console-based music player developed in Java.

## 📖 Description

This project is a simple Java-based music player that allows users to interact with music-related options through the console.

## ✨ Features

- Display available songs
- Play/select songs
- Navigate through music options
- Console-based menu

## 🛠️ Technologies Used

- Java
- OOP Concepts
- Collections
- Scanner
- Loops and Conditional Statements

## 🚀 How to Run

1. Clone this repository.
2. Open the project in a Java IDE.
3. Compile and run the Java file.
4. Follow the instructions displayed in the console.
